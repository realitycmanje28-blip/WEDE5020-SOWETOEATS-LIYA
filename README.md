## Project description

Soweto Eats is a township food delivery platform connecting customers in Soweto and JHB South with more than 200 local food vendors. Customers can find kota, braai, bunny chow, shisanyama, and other local favourites. The project promotes local businesses and aims for delivery in under 45 minutes.
